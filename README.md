# 🌯 Империя Шаурмы - Модульная версия

Idle-кликер игра в Telegram о построении империи шаурмы!

## 📁 Структура проекта

```
shawarma-empire/
├── index.html              # Главная страница (минимум кода)
├── css/
│   └── styles.css         # Все стили и анимации
├── js/
│   ├── config.js          # Конфигурация (здания, улучшения, достижения)
│   ├── sounds.js          # Звуковые эффекты
│   ├── storage.js         # Сохранение/загрузка
│   ├── game.js            # Основная логика игры
│   ├── ui.js              # Отрисовка интерфейса
│   └── main.js            # Запуск игры
└── README.md              # Этот файл
```

## 🎮 Что уже работает

✅ **Базовый геймплей:**

## 🔧 Как редактировать игру

### Добавить новое здание:

Открой `js/config.js`, найди массив `buildings` и добавь:

```javascript
{ 
  id: 13, 
  name: 'Квантовая ферма', 
  cost: 100000000, 
  owned: 0, 
  production: 500000, 
  emoji: '⚛️', 
  desc: 'Шаурма из параллельных вселенных' 
},
```

### Добавить новое улучшение:

В `js/config.js`, в массиве `upgrades`:

```javascript
// Для улучшения клика:
{ 
  id: 16, 
  name: 'Турбо-пальцы', 
  cost: 500000, 
  purchased: false, 
  clickBonus: 100, 
  type: 'click', 
  emoji: '⚡' 
},

// Для множителя производства:
{ 
  id: 17, 
  name: 'Гиперпространство', 
  cost: 1000000, 
  purchased: false, 
  productionMultiplier: 10, 
  type: 'production', 
  emoji: '🌌' 
},
```

### Добавить новое достижение:

В `js/config.js`, в массиве `achievements`:

```javascript
{ 
  id: 15, 
  name: 'Ультра магнат', 
  desc: 'Создай 10M шаурмы', 
  target: 10000000, 
  type: 'total', 
  unlocked: false, 
  reward: 500000 
},
```

### Изменить цвета интерфейса:

Открой `css/styles.css` и измени градиенты. Например, чтобы сделать синюю тему:

```css
/* В index.html найди классы from-orange-500 и замени на from-blue-500 */
```

## 📊 Типы достижений

- **total** - за общее количество шаурмы
- **clicks** - за количество кликов
- **buildings** - за количество купленных зданий
- **prestige** - за уровень престижа

## 🎨 Как добавить новые анимации

В `css/styles.css` добавь новую анимацию:

```css
@keyframes your-animation {
  0% { /* начальное состояние */ }
  100% { /* конечное состояние */ }
}

.your-class {
  animation: your-animation 1s ease-out;
}
```

Потом используй класс в HTML через `ui.js`.

## 🐛 Решение проблем

**Проблема:** Игра не сохраняется
- **Решение:** Проверь консоль браузера (F12), localStorage должен работать

**Проблема:** Не видно кнопок в магазине
- **Решение:** Добавь в `css/styles.css` скроллбар (уже есть в файле)

**Проблема:** Звуки не работают
- **Решение:** Некоторые браузеры блокируют автозвук, это нормально

**Проблема:** Числа слишком большие/маленькие
- **Решение:** В `js/config.js` измени `cost` и `production` для зданий
